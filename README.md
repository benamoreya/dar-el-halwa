# Dar El Halwa

## Présentation

Dar El Halwa est un site web pour présenter une pâtisserie et ses produits.

## Objectif

Le but de ce projet est d'appliquer les connaissances apprises en développement web.

## Technologies utilisées

* HTML
* CSS
* JavaScript

## Pages du site

* `index.html` : page d'accueil
* `carte.html` : carte des produits
* `commande.html` : page de commande

## Difficultés rencontrées

Pendant la réalisation du projet, j'ai rencontré quelques difficultés pour organiser les pages, créer les liens entre elles et intégrer les images et les fichiers multimédias. J'ai essayé de résoudre ces problèmes en vérifiant mon code et en faisant plusieurs tests.

## Conclusion

Ce projet m'a permis de pratiquer le développement web et de mieux comprendre la création d'un site internet.
